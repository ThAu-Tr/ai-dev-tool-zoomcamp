# Homework 03: Agent Relay — Containerization and Deployment

Homework 03 for AI Dev Tools Zoomcamp.

Agent Relay is a small FastAPI service for registering software agents,
delivering tasks, and recording their results. The project started as the
course-provided Agent Relay starter and was completed in a separate fork for
the Week 3 containerization and deployment assignment.

## Project repository

- [Agent Relay coursework repository](https://github.com/ThAu-Tr/ai-dev-tool-zoomcamp-03-agent-relay)

## What the assignment covers

- API integration testing against a real database
- Docker image creation and containerized API access
- PostgreSQL with Docker Compose
- Kubernetes deployment to a local kind cluster
- Persistent PostgreSQL storage, Services, and readiness checks
- Local CI/CD with `act`, Docker, and kind

See the [project README](https://github.com/ThAu-Tr/ai-dev-tool-zoomcamp-03-agent-relay/blob/main/README.md)
for setup, verification, and deployment commands.
